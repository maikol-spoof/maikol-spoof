Detalle Tecnico

Las 5 Fases del Spoof

Cada fase ataca un vector de identificacion diferente. Puedes ejecutarlas todas juntas o individualmente.

1

Limpieza FiveM

Elimina todos los datos locales, cache y tokens de FiveM y Rockstar

▼
🗃
Cache de FiveM

Elimina toda la carpeta FiveM en AppData incluyendo cache, configuracion y datos de servidor

🔑
Tokens de Licencia

Limpia los registros de CitizenFX y FiveM en HKCU que almacenan tokens de autenticacion

🎮
Rockstar Social Club

Elimina datos de Rockstar Games en AppData y registros asociados

📄
Registros CitizenFX

Limpia HKCU:\Software\CitizenFX y HKCU:\Software\FiveM completamente

// Rutas limpiadas
%LOCALAPPDATA%\FiveM
%APPDATA%\CitizenFX
HKCU:\Software\CitizenFX | FiveM
Seguro Automatico
2

Rotacion de HWID

Genera nuevos identificadores de hardware unicos a nivel de registro

▼
🔐
MachineGuid

Genera un nuevo GUID unico para la identidad principal de la maquina

📋
ProductId

Rota el identificador de producto de Windows con formato valido XXXXX-XXXXX-XXXXX-XXXXX

📅
InstallDate

Modifica la fecha de instalacion de Windows a un timestamp aleatorio

💻
HwProfileGuid

Genera un nuevo GUID para el perfil de hardware del sistema

📈
Serial SMBIOS

Rota el numero de serie del sistema en la tabla SMBIOS del registro

🛠
Nombre del Equipo

Genera un nuevo nombre de computadora con formato DESKTOP-XXXXXXX

// Claves modificadas
HKLM:\SOFTWARE\Microsoft\Cryptography -> MachineGuid
HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion -> ProductId | InstallDate
HKLM:\SYSTEM\CurrentControlSet\Control\SystemInformation -> SystemSerialNumber
HKLM:\SYSTEM\...\IDConfigDB\Hardware Profiles\0001 -> HwProfileGuid
Requiere Admin Requiere Reinicio
3

Identidad de Red

Cambia MAC de todos los adaptadores, limpia DNS y renueva DHCP

▼
🌐
Direcciones MAC

Genera MAC aleatorias validas para cada adaptador fisico y las aplica via registro + ciclo del adaptador

🔌
Cache DNS

Limpia completamente la cache de resolucion DNS del sistema

🔃
Renovacion DHCP

Libera y renueva la configuracion IP de todos los adaptadores para obtener nueva IP local

🔒
Ciclo de Adaptador

Desactiva y reactiva cada adaptador de red para aplicar la nueva MAC inmediatamente

// Operaciones de red
Set-NetAdapter -MacAddress [MAC aleatoria]
ipconfig /flushdns | /release | /renew
Requiere Admin Automatico
4

Limpieza de Rastros

Elimina temporales, prefetch, cache de Discord/Steam y logs de eventos

▼
🗃
Archivos Temporales

Limpia %TEMP%, Windows\Temp y archivos prefetch del sistema

💬
Cache de Discord

Elimina cache, GPUCache y datos de sesion de Discord que pueden vincular identidades

🎮
Cache de Steam

Limpia datos de cache de Steam que FiveM puede leer como fingerprint adicional

📄
Logs de Eventos

Limpia los logs de eventos de Windows (Application, System, Security)

Requiere Admin Seguro
5

Inicio Limpio

Genera un script de arranque para mantenimiento automatico

▼
⚡
Script de Arranque

Genera un script .bat que limpia la cache de FiveM automaticamente antes de cada sesion de juego

🔄
Mantenimiento Automatico

Puedes agregar el script al inicio de Windows para limpieza permanente
