FAQ

Preguntas Sobre VPS FiveM

Todo lo que necesitas saber antes de contratar.

¿Que framework viene instalado?▼
En los planes Pro y Elite puedes elegir entre ESX Legacy, QBCore o QBOX. Lo instalamos con la base de datos lista, jobs basicos (policia, medico, mecanico), inventario, sistema de vehiculos y economia. En Starter viene txAdmin limpio para que armes tu propio setup.
¿Puedo instalar mis propios scripts y resources?▼
Si, en todos los planes tienes acceso completo a la carpeta resources via txAdmin o FTP. Puedes subir scripts Lua, JavaScript o C#, configurar el ensure en server.cfg y reiniciar desde txAdmin. En Elite tienes SSH para control total.
¿Que version de artifacts usan?▼
Siempre la ultima version estable de FXServer (recommended channel). Actualizamos regularmente y te avisamos antes de cambios mayores. Si necesitas una version especifica, la configuramos.
¿Viene con base de datos MySQL?▼
En Pro y Elite si: MariaDB con oxmysql, phpMyAdmin, charset utf8mb4 y backups automaticos del SQL. En Starter puedes usar SQLite o contratar MySQL como addon.
¿Que metodos de pago aceptan?▼
PayPal, tarjetas (Visa, Mastercard), criptomonedas (BTC, ETH, USDT, LTC) y transferencias locales LATAM. Acceso inmediato tras confirmacion.
¿Pueden migrar mi server actual?▼
Si, migracion gratis. Movemos server-data, resources, base de datos, server.cfg y txAdmin config. Menos de 1 hora, coordinamos contigo para minimo downtime.
¿Cuantos jugadores aguanta realmente?▼
Starter corre bien con 20-32 jugadores con scripts moderados. Pro maneja 40-64 con framework completo. Elite soporta 80-128+ con OneSync Infinity y roleplay pesado. Necesitas mas? Hablamos y armamos un plan custom.
¿Puedo cambiar de plan o ubicacion?▼
Si. Upgrade o downgrade al instante con ajuste proporcional. Cambio de datacenter sin costo, migramos todo coordinando contigo.

¿Listo para Lanzar tu Server FiveM?

Elige tu plan y ten tu servidor corriendo con txAdmin, framework y base de datos listos. Sin complicaciones.
